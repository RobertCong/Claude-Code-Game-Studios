## Phase 4: API 边界

定义模块之间的公共契约。对每个边界：

- 模块向系统其余部分暴露的接口是什么？
- 入口点（函数/信号/属性）有哪些？
- 调用方必须遵守哪些不变量？
- 模块必须向调用方保证什么？

用伪代码或项目实际使用的语言（来自技术偏好）编写。
这些会成为程序员实现所依据的契约。

**引擎感知检查**：如果任何接口使用引擎专属类型（例如
Godot 中的 `Node`、`Resource`、`Signal`），标出版本，并验证该类型
在目标引擎版本中存在且签名未变更。

取得用户对 API 边界的批准，然后记录到
`production/session-state/active.md`；它们在 Phase 7 写入。
